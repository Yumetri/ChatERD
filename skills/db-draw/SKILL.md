# DB 그림 편집

사용자가 지정한 기존 UTF-8 `.mmd` 경로와 요청·필요한 대화 문맥을 입력으로 받는다. 파일이 불명확하면 질문한다. 임의 스키마를 선택하거나 기본 파일을 생성하지 않는다.

이 스킬의 실제 위치에서 `../../runtime/cli.mjs`를 찾는다. `.agents/skills` 연결이면 심볼릭 링크의 실제 위치를 먼저 확인한다. 빌드되지 않았으면 `node <런타임> setup`을 실행한다.

1. 뷰어가 없으면 `node <런타임> preview <사용자가 지정한 경로>`로 연다. 이미 열려 있으면 재사용한다. `status <동일한 경로>`로 `review_mode`, `file_conflict`, `unsaved_draft`, `active_candidates`를 확인한다.
2. `review_mode: automatic`이고 충돌·미저장 초안·진행 중인 검수 후보가 없으면 호스트가 지정한 `.mmd`를 직접 수정한다. `check <동일한 경로>`로 새 버전의 정상 렌더링을 확인한다. 독립 Codex 실행과 PNG 검수를 생략한다. 테이블·컬럼 추가도 요청한 설계만 반영하고 기존 배치와 설계 메타데이터를 보존한다.
3. `review_mode: strict`(최초 또는 오류 후), 렌더 실패, 또는 명시적 이미지 검수 요청이면 `draw <동일한 경로>`에 요청과 문맥을 stdin으로 전달한다. 격리 실행이 후보 생성·PNG 검수·저장을 담당한다. 정상 이미지 검수 통과가 기록되면 자동 경로로 돌아간다. 요청을 셸 문자열에 보간하지 않는다.
4. 정상 자동 경로는 `check`의 버전·해시·렌더 성공만 보고한다. PNG를 보지 않았으면 이미지 검수했다고 말하지 않는다. 외부 파일 저장 후 오류가 나면 수정한 파일은 디스크에 남으며 마지막 정상 그림을 유지한다. 오류를 숨기거나 정상 렌더만으로 엄밀 검수 상태를 해제하지 않는다. 충돌은 초안을 보존하고 자동 덮어쓰지 않는다.

검수 상태는 파일 경로별로 런타임에 보존되며 재실행 후에도 이어진다. 상태가 없거나 손상되면 최초 검수부터 시작한다. 정상 자동 경로도 파서·메타데이터·렌더 결과·저장 충돌 검사는 유지한다. 가독성 저하가 렌더 오류로 검출되지 않을 수 있으므로 사용자가 문제를 지적하면 이미지 검수 경로를 사용한다.

테이블·컬럼·키·관계·카디널리티는 사용자가 결정한 범위만 변경한다. 설계 판단이 필요한 모호함은 질문한다. 엄밀 검수 중 자동 보정은 문법과 지원되는 시각 설정에 한정하며 최대 2회다. 세부 절차는 [실행 규칙](../../references/isolated-workflow.md), 엄밀 시각 검수는 [배치 피드백](../../references/layout-feedback.md)에 있다. 참고 문서는 엄밀 격리 실행에 전달된다.

작성하는 테이블명과 필드명은 반드시 영어 식별자를 사용한다. 사용자가 한글 업무명으로 요청하면 의미에 맞는 영어 이름으로 작성하고, 테이블의 한글 설명은 Mermaid 별칭으로 붙인다. 예: `SALES_REP["영업사원"]`과 `uuid id PK`, `string name`. 필드명에 한글을 쓰거나 필드에 한글 표시명·주석을 추가하지 않는다. 관계 선언과 설계·배치 메타데이터는 한글 별칭이 아닌 영어 테이블명을 참조한다. 기존 이름의 일괄 변경은 사용자 요청 범위에 포함될 때만 수행한다. 표기 예시는 [명시적 설계 정보의 이름 표기 규칙](../../references/schema-metadata.md#이름-표기-규칙)을 따른다.

작성하는 모든 연관관계에는 관계 의미를 설명하는 라벨을 반드시 한글로 붙인다. 설명을 생략하거나 영어로 작성하지 않는다. 예: `SALES_REP |o..o{ CAR : "판매"`. 대응하는 `@db-camp` 외래키 메타데이터가 있으면 `label`도 동일한 한글 설명으로 맞춘다. 관계의 설명만 바꿀 때는 참조 컬럼·NULL 허용 여부·카디널리티를 그대로 보존한다.

엄밀 시각 검수에는 선 분포도 포함한다. `get_preview`의 PNG와 `layout_feedback`을 함께 읽고 같은 통로의 평행선을 일정한 간격으로 나누는 것을 목표로 한다. 기본 목표는 SVG 원본 좌표에서 24px이며 엔진이 보장하는 값은 아니다. 정상 자동 경로에서 간격 진단만으로 이미지 검수를 반복하거나 임의 배치를 보정하지 않는다.

뷰어 직접 편집은 정상 렌더 후 원본에 자동 저장된다. 사람의 입력을 자동으로 고치지 않는다. 이미지 파일은 UI 다운로드 버튼으로만 저장하며, 검수 이미지를 파일로 수집하거나 다운로드 폴더를 탐색하지 않는다.

Mermaid 12 파서와 독립 SVG/ELK 뷰어를 사용한다. [명시적 설계 정보](../../references/schema-metadata.md)의 NULL·복합 키·FK 컬럼 대응도 원본 설계의 일부이며 추정하거나 시각 보정으로 변경하지 않는다. 참고 문서는 격리 실행에 전달된다.
